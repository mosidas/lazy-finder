# lazy-finder のオプションとキー

lazy-finder の起動時のオプション、環境変数、キーの割り当てを一覧にする。インストールと最初の操作は、[lazy-finder の README](../README.md) の手順で行う。

## オプションと環境変数

| 指定 | 内容 | 既定値 |
| :- | :- | :- |
| `--theme <名前>` | 画面のテーマ。`min-light` と `ayu-light` から選択する | `min-light` |
| `LAZY_FINDER_THEME` | `--theme` と同じ。`--theme` を指定したときは `--theme` が優先される | - |
| `<ディレクトリ>` | 起動時に開くディレクトリ | カレントディレクトリ |

`--theme` は起動するディレクトリより前に書く。後ろに書いた `--theme` は無視される。`min-light` と `ayu-light` は、端末の背景色によらず明るい配色で描画する。

```sh
lazy-finder --theme ayu-light ~/Projects
LAZY_FINDER_THEME=ayu-light lazy-finder
```

## キー

| キー | 動作 |
| :- | :- |
| `↑`/`k`, `↓`/`j` | カーソル移動 |
| `g` / `G` | 先頭 / 末尾へ |
| `enter` / `l` / `→` | フォルダーに入る / ファイルを標準アプリで開く |
| `h` / `←` / `backspace` | 親フォルダーへ |
| `~` | ホームディレクトリへ |
| `space` | 選択(マーク)のトグル |
| `y` / `x` | コピー / 切り取り |
| `p` | 貼り付け(カレントへ) |
| `d` | ゴミ箱へ移動(確認あり) |
| `r` | 名前変更 |
| `n` | 新規フォルダー |
| `o` | 標準アプリで開く |
| `e` | VS Code で開く |
| `.` | 隠しファイルの表示切替 |
| `R` / `Ctrl+R` | 再読込 |
| `?` | ヘルプ |
| `q` / `Ctrl+C` | 終了 |

- 選択した項目があるとき、`y`・`x`・`d` は選択したすべての項目を対象にする。選択が無いときは、カーソルの項目を対象にする。
- `d` は項目を完全には削除せず、macOS では `~/.Trash` へ、Linux では freedesktop のゴミ箱へ移動する。
- `e` は、カレントのフォルダーか、カーソルがフォルダーにあるときはそのフォルダーを `code` コマンドで開く。`code` コマンドは、VS Code の「シェルコマンド: PATH 内に 'code' コマンドをインストール」で PATH に追加する。
